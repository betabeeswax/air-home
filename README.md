# AIR Hub

Home page linking all AIR apps on **Vercel** and **Netlify**.

## Live

Repo: https://github.com/betabeeswax/air-home  
Import this repo on Vercel to host the hub (e.g. `air-home.vercel.app`).

## Sites included

### Vercel
- [Quiet Chat](https://quietchat.vercel.app)
- [AIR Dictionary](https://air-dictionary.vercel.app)
- [AIR Maps](https://air-maps.vercel.app)
- [AIR Docs](https://air-docs.vercel.app)

- [AIR Player](https://air-player.vercel.app)
- [AIR Retro OS](https://air-retro-os.vercel.app)
